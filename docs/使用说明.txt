心率悬浮窗 v1.1 · 使用说明
============================

【安装版（推荐）】
  双击「心率悬浮窗安装程序.exe」，选择安装目录并点击「安装」。
  默认安装到 %LOCALAPPDATA%\Programs\HeartRateOverlay。
  安装完成后桌面会创建「心率悬浮窗」快捷方式。
  配置、历史记录和日志保存在安装目录的 cache 文件夹。
  安装包包含完整运行文件，不需要另外复制 _internal 文件夹。

【免安装版】
  「心率悬浮窗.exe」仍可直接运行；如果旧的 AppData 目录不可写，启动器会自动选择
  当前用户可写的专属目录。普通使用建议安装「安装版」。
如果 Windows 提示"文件不安全"/SmartScreen：
  1. 右键安装程序 → 属性 → 勾选「解除锁定」→ 确定。
  2. 双击后点「更多信息」→「仍要运行」。
  程序未做数字签名，所以会有此提示；SHA256 哈希见 SHA256SUMS.txt。

一、启动
  从桌面双击「心率悬浮窗」快捷方式。

二、主窗口显示方式
  右上角「显示方式」可切换：
    · 单个设备：显示当前选中设备的大号心率和历史曲线。
    · 多设备同显（默认）：所有设备的心率、最低 / 平均 / 最高 / 采样、3 分钟实时曲线
      和所选范围的历史曲线同时以紧凑卡片展示；顶部可统一切换历史范围。
      点击多设备卡片上的「详情」即可切回单个设备大图。
  左侧「我的设备」中，已断开的设备会单独放在「已断开」分组；
  点击「已断开」标题可以折叠或展开该分组。

三、连接设备
  1. 打开手环 / 手表的「心率广播」（部分品牌需在官方 App 内开启）。
  2. 确保电脑蓝牙已打开，设备靠近电脑；建议先断开手机与设备的连接。
  3. 点击右上角「＋ 选择设备」→「开始扫描」。
  4. 勾选设备（可多选）→「连接所选设备」，或直接点某一行的「连接」。
  5. 连接成功后，左侧设备卡片会显示实时心率。

四、悬浮窗
  1. 点击设备卡片上的「显示悬浮窗」。
  2. 整个悬浮窗框都可以按住拖动。
  3. 四个角有缩放手柄，拖动可改变窗口大小；文字会随框大小缩放。
  4. 悬浮窗正下方中心有「锁定 / 隐藏」按钮：
       · 锁定：保持最上层并点击穿透，按钮会自动隐藏；
       · 隐藏：关闭悬浮窗，可从主窗口或托盘重新显示。
  5. 解锁方式：主窗口点「解锁」、托盘菜单「解锁全部悬浮窗」或按 Ctrl+Alt+L。
  6. 点击卡片上的「Aa」可自定义文字、字体（下拉框）、字号、颜色、字距、背景、描边、
     阴影等；字号、间距、内边距等输入框右侧有上下调节箭头。

五、多设备
  可同时连接多个手环 / 手表；每个设备都有独立悬浮窗和独立样式。
  主窗口支持多设备同显，可切换单个设备；左侧「已断开」分组可折叠。

六、全屏说明
  无边框全屏、窗口化全屏：悬浮窗可在游戏上方显示（推荐）。
  独占全屏（Exclusive Fullscreen）：Windows 系统不允许任何普通窗口覆盖，请把游戏
  改成「无边框窗口 / 窗口化全屏」。

七、快捷键与托盘
  Ctrl+Alt+L  锁定 / 解锁悬浮窗
  Ctrl+Alt+H  显示 / 隐藏全部悬浮窗
  关闭主窗口默认最小化到系统托盘，右键托盘图标可退出。

八、数据与隐私
  所有数据只保存在本机，不上传网络。
  安装版数据目录：安装目录\cache\
    config.json      设备、收藏、样式、位置
    history.sqlite3  心率历史
    app.log          运行日志
  安装包完整运行文件位于安装目录内，缓存位于安装目录的 cache\。
  可在设置中清空历史、修改保留天数或打开数据目录。

九、常见问题
  Q: 第一次启动比较慢？
    A: 安装程序会先解压完整运行文件；之后从桌面快捷方式启动即可。
  Q: 扫描不到手环？
    A: 确认手环已开启心率广播、电脑蓝牙已开启、手环未连接手机；靠近电脑后重新扫描。
  Q: 连接成功但没有心率？
    A: 该设备可能没有标准 BLE 心率服务，或未开启广播；请查看 app.log 与设备说明。
  Q: 悬浮窗在游戏里看不到？
    A: 确认游戏使用无边框 / 窗口化全屏，而不是独占全屏；并确认悬浮窗处于「显示」状态。
  Q: SmartScreen 提示未知发布者？
    A: 这是未签名程序的正常提示；按上面的「解除锁定 / 仍要运行」操作。

心率数据仅供参考，不构成医疗建议。
