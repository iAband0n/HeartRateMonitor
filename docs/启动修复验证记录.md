## SmartScreen 未知发布者

用户确认的提示为“Windows 已保护你的电脑”或“未知发布者”。当前计算机没有可用的可信代码签名证书，因此交付文件仍为未签名，SmartScreen 提示尚未消除。移除本地下载标记不能代替发布者签名；可信签名也不保证立即建立 SmartScreen 信誉。

具备带私钥的代码签名证书后，可使用：

```powershell
.\build.ps1 -CertificateThumbprint "证书指纹"
```

仅重建外层启动器、复用本次保存的原始运行文件：

```powershell
.\tools\build_single_exe.ps1 -ExistingPayload build_single\payload.zip -CertificateThumbprint "证书指纹"
```

没有安装自签名根证书，也没有修改 Windows 安全设置。
