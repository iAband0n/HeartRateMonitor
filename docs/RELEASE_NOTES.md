# GitHub Release Notes — v1.1

## 心率悬浮窗 v1.1

### 更新内容

- 单设备详情视图遇到较矮窗口时支持纵向滚动，实时心率曲线和最低、平均、最高、采样统计框不会互相遮挡。
- “采样”数据表示最近 5 分钟内收到的心率读数条数；实时曲线显示最近 3 分钟的数据。
- 关于界面新增项目地址和作者主页链接。
- 修复自动构建时运行文件输出目录不一致的问题。

### 下载

- `心率悬浮窗安装程序.exe` — 推荐，Windows 10/11 64 位安装包；
- `心率悬浮窗.exe` — 免安装备用版本；
- `SHA256SUMS.txt` — 下载文件的 SHA256 校验值。

安装时选择父目录，安装器会自动创建 `HeartRateMonitor` 子目录。例如选择
`D:\Program Files`，最终安装目录为 `D:\Program Files\HeartRateMonitor`。
默认目录为 `%LOCALAPPDATA%\Programs\HeartRateMonitor`。安装器会创建桌面快捷方式，
配置、历史记录和日志保存在安装目录的 `cache` 文件夹。

### 已知限制

- 仅支持标准 BLE 心率服务（0x180D / 0x2A37）；部分设备需在官方 App 开启心率广播。
- 程序未进行代码签名，Windows SmartScreen 可能提示「未知发布者」。
- 心率数据仅供参考，不构成医疗建议。
