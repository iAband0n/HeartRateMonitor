# GitHub Release Notes — v1.0.0

## 心率悬浮窗 v1.0.0

一个 Windows 桌面心率悬浮窗应用：通过 BLE 读取手环 / 手表 / 心率带的标准心率服务，
显示在可自定义、始终置顶、可锁定点击穿透的悬浮窗中。

### 下载与安装

- `心率悬浮窗安装程序.exe` — 推荐，Windows 10/11 64 位安装包；
- `心率悬浮窗.exe` — 免安装备用版本。

使用安装包时，双击安装程序并选择父目录；安装器会自动创建 `HeartRateMonitor` 子目录。
例如选择 `D:\Program Files`，最终目录为 `D:\Program Files\HeartRateMonitor`。默认目录为
`%LOCALAPPDATA%\Programs\HeartRateMonitor`。安装器会请求管理员权限，安装完成后会在桌面创建快捷方式，
配置、历史记录和日志保存在安装目录的 `cache` 文件夹。

安装包包含完整运行文件，不需要额外复制 `_internal` 文件夹，也不再依赖
`%LOCALAPPDATA%\HeartRateOverlay` 的旧运行目录。
安装信息会注册到 Windows“已安装的应用”，安装目录内也提供 `uninstall.exe`。
### 首次运行提示

程序未做数字签名，Windows SmartScreen 可能提示「未知发布者」：

- 右键安装程序 → 属性 → 勾选「解除锁定」；
- 运行时点「更多信息 → 仍要运行」。

SHA256 校验值见 `SHA256SUMS.txt`。

### 功能

- 多设备同时连接、主窗口多设备同显（可切换单个设备）；每张卡片同时显示心率、
  最低 / 平均 / 最高 / 采样、实时曲线和所选范围的历史曲线；
- 已断开设备独立分组，可折叠；
- 自定义模板 / 字体下拉框 / 字号 / 颜色 / 字距 / 背景 / 描边 / 阴影；数字输入框带上下箭头；
- 悬浮窗整框拖动、四角缩放、文字随框缩放，底部中心锁定 / 隐藏按钮；
- 锁定点击穿透、持续置顶；
- 心率历史折线图（5 分钟 / 30 分钟 / 1 小时 / 6 小时 / 24 小时）与 CSV 导出；
- 收藏 / 常用设备、自动重连、配置持久化；
- 托盘、Ctrl+Alt+L、Ctrl+Alt+H。

### 全屏说明

- 无边框 / 窗口化全屏：支持；
- 独占全屏（Exclusive Fullscreen）：Windows 不允许普通窗口覆盖，请改用无边框 / 窗口化全屏。

### 已知限制

- 仅支持标准 BLE 心率服务（0x180D / 0x2A37）；部分设备需在官方 App 开启心率广播。
- 未做代码签名。
- 心率数据仅供参考，不构成医疗建议。
