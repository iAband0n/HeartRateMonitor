心率悬浮窗 1.1 · 首次运行必读
================================

一、安装与运行
  1. 下载并双击「心率悬浮窗安装程序.exe」。
  2. 选择父目录，安装器会自动创建 HeartRateMonitor 子目录；默认是：
       %LOCALAPPDATA%\Programs\HeartRateMonitor
     例如选择 D:\Program Files，最终安装目录是 D:\Program Files\HeartRateMonitor。
     安装器会请求管理员权限，以便写入受保护的安装目录。
  3. 安装完成后，桌面会创建「心率悬浮窗」快捷方式，Windows“已安装的应用”中也会出现卸载项。
  4. 从桌面快捷方式启动程序。安装目录内的 cache 文件夹保存配置、历史记录和日志。
  5. 安装包包含完整运行文件，不需要另外复制 _internal 文件夹。

  免安装版「心率悬浮窗.exe」仍可直接运行，但推荐使用安装程序。
  卸载可在 Windows“设置 → 应用 → 已安装的应用”中进行，也可以运行安装目录内的 uninstall.exe。
二、Windows 提示"文件不安全"或 SmartScreen
  程序没有购买代码签名证书，Windows 会对下载的 exe 给出提示，这是正常现象。
  1. 右键安装程序 → 属性 → 勾选「解除锁定」→ 确定。
  2. 双击 exe，若出现 SmartScreen，点「更多信息」→「仍要运行」。
  3. 可用 SHA256SUMS.txt 核对文件哈希。

  如果杀毒软件隔离了文件，请在保护历史中恢复并加入信任；不要把整个磁盘或
  Windows Defender 关闭。

三、连接手环
  1. 在手环 / 手表的官方 App 中开启「心率广播」（部分型号叫「广播心率」）。
  2. 电脑打开蓝牙，手环靠近电脑；建议先断开手环与手机的连接。
  3. 打开程序，点右上角「＋ 选择设备」→「开始扫描」。
  4. 勾选设备 →「连接所选设备」。
  5. 连接后在左侧设备卡片点「显示悬浮窗」；拖动到合适位置后点「锁定」。
  6. 主窗口「显示方式」可切换「单个设备 / 多设备同显」；已断开设备在左侧独立分组，
     点击「已断开」标题可折叠或展开。

四、悬浮窗操作
  · 整个悬浮窗框都可以拖动；
  · 四个角可拖动缩放，文字随框大小缩放；
  · 正下方中心的「锁定 / 隐藏」按钮随框宽自动居中；
  · 锁定后按钮隐藏、鼠标点击穿透，可在主窗口 / 托盘 / Ctrl+Alt+L 解锁。

五、全屏说明
  无边框全屏 / 窗口化全屏：悬浮窗可以正常置顶。
  独占全屏（Exclusive Fullscreen）：Windows 不允许普通窗口覆盖，请把游戏改成
  「无边框窗口 / 窗口化全屏」。

六、数据位置
  安装版：安装目录\cache\
    config.json      设备、收藏、样式、位置
    history.sqlite3  心率历史
    app.log          运行日志

心率数据仅供参考，不构成医疗建议。
